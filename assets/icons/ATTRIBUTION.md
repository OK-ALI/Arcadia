# Arcadia Interface Icon Attribution

The SVG interface icons in this folder were provided by the project owner for
Arcadia Core v0.3.0 UI polish.

Many of these icons were sourced from Flaticon. Keep the original Flaticon
license terms and downloaded asset records available with the project owner.
When an icon requires attribution, credit the original Flaticon author according
to the license attached to that downloaded icon.

Arcadia uses these SVGs as monochrome interface masks so they can inherit the
current theme color across dark, light, and preset themes.
